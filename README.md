# genai-otel-instrument-node

OpenTelemetry auto-instrumentation for GenAI applications on Node.js / TypeScript: traces,
token and cost attribution, GPU / energy / CO2 metrics and evaluation signals, in the
same wire format as the Python library `genai-otel-instrument`.

**Private repository. Not published to any public registry.**

- Package: `@traceverse/genai-otel-instrument`
- Minimum runtime: Node 18
- Reference implementation: `genai_otel_instrument` v1.30.0

Status: scaffold. See `CLAUDE.md` for the engineering rules.
